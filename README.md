# Tower Defense Simulator

A polished browser-based tower defense game built with React, TypeScript, Vite, and HTML5 Canvas.

## Features

- 5 waves with escalating enemy compositions
- 3 tower types with drag-and-drop placement
- Tower upgrades (3 levels) and selling
- Final boss on wave 5
- Pause and 2x speed controls

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Controls

- Drag tower cards from the shop onto the map
- Click a placed tower to open the upgrade panel
- Click elsewhere or press `Esc` to deselect
- Use **Start Wave** to begin each wave
- Pause / 2x speed buttons in the HUD

## Tech Stack

- React + TypeScript
- Vite
- HTML5 Canvas rendering
- CSS for UI
